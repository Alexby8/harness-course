Используй проектный MCP qmd либо локальный CLI `node llm-wiki/tools/qmd/node_modules/@tobilu/qmd/bin/qmd` из корня проекта.
Ищи точный термин через BM25, получи полный документ и сверь релевантные строки. Для смыслового поиска используй query по коллекции с эмбеддингами. Каноническая инструкция из установленного пакета доступна в `llm-wiki/tools/qmd/node_modules/@tobilu/qmd/skills/qmd/SKILL.md`. Команды из неё выполняй для индекса текущего проекта. Для ответа о правиле дополни результат ссылками на raw и соответствующий символ в исходниках.
