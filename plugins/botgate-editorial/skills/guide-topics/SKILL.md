Прочитай `content/guides/README.md` из текущего учебного проекта. Сопоставь задачи читателя в `content/guides/current.json` и всех `content/guides/packages/*.json`. Объедини совпадающие slug при сравнении. Посмотри разделы ближайших статей и глубину двух практических примеров. Рабочий каталог сайта хранится в таблице `guides`, для подбора тем в учебной копии используется снимок.

Предложи запрошенное число разных задач (по умолчанию пять). На каждую дай заголовок, проблему читателя, конкретный проверяемый результат и ближайшее руководство со slug, объясни отличие по результату. Учитывай PHP, Laravel, Telegram Bot API и Mini Apps в зависимости от запроса. BotGate — прокси для Bot API. Калькуляторы, каталоги и подобные проекты служат примерами для читателя.

Заверши ответ списком тем. Выбор остаётся за пользователем. В этом режиме работай только на чтение.
