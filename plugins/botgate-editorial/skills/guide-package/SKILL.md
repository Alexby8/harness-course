name: guide-package
description: Запусти подготовку одного руководства BotGate по явно выбранной пользователем теме.
---

Если тема не названа, попроси пользователя её указать.
Прочитай [профиль редактора](../../agents/botgate_editor.toml). Вызови одного субагента через `spawn_agent` с `fork_turns="none"`. Для `task_name`, `model` и `reasoning_effort` возьми из профиля соответственно `name`, `model` и `model_reasoning_effort`.
В сообщении передай инструкции из `developer_instructions`, формулировку темы, корень учебного проекта и абсолютный путь к корню установленного плагина (на два уровня выше каталога этого SKILL.md).
Дождись ответа редактора и передай пользователю результат.
