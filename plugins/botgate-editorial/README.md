# Редакция BotGate для Codex

Плагин помогает редактору сайта выбрать тему и подготовить одну статью для каталога руководств. Каждая команда запускается отдельно. [Пример двух вызовов и проверенный пакет](DEMO.md).

## Подключение из PowerShell

Откройте PowerShell в корне учебной копии, на ветке `hw/lesson-04`. На новом компьютере сначала выполните `codex login`, если CLI ещё не авторизован.

```powershell
codex plugin marketplace add .
codex plugin add botgate-editorial@harness-course
codex plugin list --marketplace harness-course --json
```

В массиве `installed` у `botgate-editorial@harness-course` будут `installed: true` и `enabled: true`. Codex устанавливает копию плагина в свой кэш. После обновления ветки повторите установку и начните новый сеанс.

## Предложить темы

```powershell
codex exec -s read-only '$botgate-editorial:guide-topics Предложи пять тем для технических руководств BotGate.'
```

Количество можно изменить. Для каждой темы получите задачу читателя, ожидаемый результат и отличие от ближайшего материала. Для этой команды достаточно файлов репозитория.

## Подготовить руководство

Выберите тему, скопируйте её формулировку в команду. Ниже пример для темы о встречах из демонстрационной подборки.

```powershell
codex --search exec -s workspace-write '$botgate-editorial:guide-package Подготовь руководство по выбранной теме «Как выбрать дату встречи с помощью Telegram-опроса и опубликовать итог». Вызови редактора по профилю плагина.'
```

Для интерактивной работы запустите `codex` из корня проекта и введите текст из одинарных кавычек. В PowerShell эти кавычки сохраняют знак `$`. Готовая статья находится в `content/guides/packages/<slug>.json`. Редактор вернёт путь, команду dry-run и результат практической проверки. При повторном выборе темы готового пакета скилл укажет совпадение.

[Скилл подбора тем](skills/guide-topics/SKILL.md) работает на чтение. [Скилл подготовки статьи](skills/guide-package/SKILL.md) при явном вызове загружает [профиль редактора](agents/botgate_editor.toml). В проверенном Codex CLI для Windows команда `spawn_agent` принимает имя задачи, модель, уровень рассуждения и сообщение с инструкцией. Скилл передаёт эти значения из TOML и указывает редактору путь к установленному скиллу. Поэтому профиль лежит в самом пакете. Общие инструкции приложения для этого не нужны.

## SQLite на новом компьютере

Для dry-run нужны зависимости из `composer.lock`, PHP с `pdo_sqlite` и учебная база с миграциями. На проверенной машине использовался PHP 8.5.10. Проверьте `php -v` и `php --ri pdo_sqlite` в том PowerShell, из которого запускаете Codex. При нескольких установках PHP поставьте нужную папку первой в `$env:Path` на время сеанса.

В свежем клоне для создания локального окружения выполните команды ниже. В уже настроенной учебной копии этот шаг можно пропустить.

```powershell
Copy-Item .env.example .env
composer install
php artisan key:generate
New-Item -ItemType File database/database.sqlite
php artisan migrate
php artisan guides:import content/guides/current.json
```

Последняя команда наполняет **новую учебную базу** 16 статьями из снимка. При подготовке новой статьи редактор запускает только `guides:import <путь-к-пакету> --dry-run`.
