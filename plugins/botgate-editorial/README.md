# Написание статей для BotGate

На сайте BotGate есть раздел «Руководства» со статьями о том, как интегрировать Telegram-ботов с сайтами и приложениями через Telegram Bot API. Плагин автоматизирует две задачи редакции. По первой команде он предлагает темы с учётом опубликованных руководств. Когда редактор выбрал тему, по второй команде плагин готовит и проверяет статью.

## Подключение

Выполните в PowerShell из корня учебного проекта на ветке `hw/lesson-04`. Для первого входа в Codex используйте `codex login`.

```powershell
codex plugin marketplace add .
codex plugin add botgate-editorial@harness-course
```

## Предложить темы

```powershell
codex exec -s read-only '$botgate-editorial:guide-topics Предложи пять тем для руководств BotGate.'
```

Для каждой темы получите задачу читателя, ожидаемый результат и отличие от ближайшей статьи. Число тем можно изменить.

## Написать статью

Подставьте выбранную тему в команду.

```powershell
codex --search exec -s workspace-write '$botgate-editorial:guide-package Подготовь руководство по теме «Как выбрать дату встречи с помощью Telegram-опроса и опубликовать итог».'
```

Редактор сохранит статью в `content/guides/packages/<slug>.json`, проверит пакет через `guides:import --dry-run` и для практической статьи запустит пример.
