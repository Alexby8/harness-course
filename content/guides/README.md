# Руководства учебного BotGate

Страницы каталога читаются из таблицы `guides`. При первом запуске миграция добавляет 14 исходных статей из `database/data/guides.json`.

## Примеры пакетов

В `packages/` оставлены два примера формата, на котором будет работать учебный плагин:

- [Калькулятор стоимости услуг в Telegram Mini App](packages/telegram-mini-app-service-calculator.json)
- [Каталог товаров для Telegram-бота из Google Таблиц](packages/telegram-bot-google-sheets-catalog.json)

[Команды импорта и ссылки на локальные страницы](../../README.md#два-дополнительных-руководства). После импорта обоих пакетов опубликовано 16 статей. Обе статьи ссылаются на исходники примеров в [botgate-examples](https://github.com/Alexby8/botgate-examples).

## Каталог для подбора тем

`current.json` содержит экспорт 16 статей учебного приложения. При подготовке новой темы по нему можно проверить, какие задачи читателей уже разобраны. Если состав статей изменился, обновите снимок из корня учебного проекта:

```shell
php artisan guides:export content/guides/current.json
```
