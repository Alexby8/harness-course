## Структура и архитектура

- `bot-gate-main/` — отдельный Git-репозиторий основного Laravel-приложения.
- `bot-gate-proxy/` — отдельный Git-репозиторий stateless Go Proxy в Docker.
- `botgate-php-sdk/` — отдельный Git-репозиторий PHP SDK для клиентов BotGate.
- `botgate-laravel/` — отдельный Git-репозиторий интеграции SDK с Laravel 11–13;
  Laravel 13 требует PHP 8.3+, Laravel 11/12 — PHP 8.2+.
- `botgate-examples/` — отдельный публичный Git-репозиторий примеров к статьям.
  Структура: `examples/<slug-статьи>/<язык>/`, сейчас реализация `php`.
  Исходники поддерживаются здесь; верхняя карточка статьи ссылается на папку
  примера в `main`, ссылки на конкретный код при необходимости — на проверенный коммит.
  Не возвращать дубли примеров и ZIP в основное приложение.
- Основной сервер хранит постоянные данные и выполняет бизнес-логику;
  зарубежные proxy-ноды передают запросы к Telegram. Не переносить бизнес-логику
  и постоянные пользовательские данные в Go Proxy.
- Общая схема и границы компонентов: [docs/architecture.md](docs/architecture.md).
- Миграция завершена, прежний сервер удалён. Не возобновлять старые задачи
  миграции и приёмки без нового запроса пользователя.
