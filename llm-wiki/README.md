# База знаний BotGate

База помогает ответить на два вопроса о BotGate. Какое поведение обещано пользователю? Где оно реализовано и проверено в учебной копии? QMD ищет подходящие фрагменты в документах, коде и тестах. По команде автора агент читает первоисточники, сопоставляет свидетельства и записывает выводы в wiki.

## Материалы

[Реестр источников](sources.md) содержит исходное ТЗ, руководство по интеграции, контракт публичного API и выдержки из проектных соглашений. В нём указаны исходные пути, границы выдержек и контрольные суммы. Код читается из текущей ветки. [Схема wiki](SCHEMA.md) задаёт формат страниц, ссылок на источники и записей о расхождениях. В [каталоге wiki](wiki/index.md) сейчас 13 страниц по девяти источникам. С [обзора BotGate](wiki/overview.md) можно перейти к интеграции ботов, редакторскому процессу и аналитике. [Журнал](wiki/log.md) показывает, что добавил каждый источник.

Схема, утилита wiki.mjs и три операции wiki взяты из учебного [примера second-brain](https://github.com/hardcourse/ai-harness-1/tree/736478195c9ef808e7de41b1e40df5fea5fb0b41). Для поиска подключён [QMD](https://github.com/tobi/qmd). Четыре скилла доступны в [.agents/skills](../.agents/skills).

## Запуск в Codex

Открой учебный репозиторий в Codex. Выбери запрос под текущую задачу.

- Поиск по первоисточникам — `$qmd Найди в исходных документах правила доставки webhook и покажи соответствующие реализацию и тест в текущей ветке.`
- Обработка новых материалов — `$wiki-ingest Обработай новые или обновлённые источники BotGate. Для каждого правила проверь реализацию и тесты, укажи источники, зафиксируй расхождения и открытые вопросы.`
- Вопрос к составленной базе — `$wiki-query Что происходит при повторной доставке одного обновления Telegram? Приведи ссылки на страницу wiki, источник и код.`
- Проверка базы — `$wiki-lint Проверь ссылки, подтверждение выводов кодом и противоречия между страницами.`

## Локальная установка на Windows

Команды запускаются из корня репозитория в PowerShell. В этой копии установка проверена на Node.js 24 с версией npm из комплекта Node.js.

```powershell
Push-Location llm-wiki/tools/qmd
$npmCli = Join-Path (Split-Path (Get-Command node).Source) 'node_modules/npm/bin/npm-cli.js'
node $npmCli ci
Pop-Location
./llm-wiki/tools/setup-qmd.ps1
$qmd = 'llm-wiki/tools/qmd/node_modules/@tobilu/qmd/bin/qmd'
node --use-system-ca $qmd pull
node $qmd embed
codex mcp get qmd --json
```

Скрипт создаёт индекс в `.qmd/`, регистрирует коллекции и добавляет QMD как stdio-сервер в локальный `.codex/config.toml`. Открой новый чат в учебном проекте после установки. Три модели QMD загружаются при первоначальной установке и затем работают из кеша пользователя. Параметр --use-system-ca подключает доверенные корневые сертификаты Windows для загрузки через Node.js. Для обновления индекса после изменения материалов выполни `node $qmd update` и `node $qmd embed`.

| Коллекция | Что можно найти |
| --- | --- |
| raw | Девять первичных документов и выдержек из рабочего проекта |
| code | PHP-код приложения, маршруты, конфигурацию, миграции, ресурсы и тесты учебной копии |
| wiki | Каталог, журнал и созданные агентом страницы |

Эти команды показывают совпадения в коде, состояние индекса и материалы, ожидающие обработки.

```powershell
node $qmd search 'WebhookIngress' -c code -n 3 --files
node $qmd status
node llm-wiki/tools/wiki.mjs status
node llm-wiki/tools/wiki.mjs lint
```

## Проверка на повторной доставке

В новом чате учебного проекта можно задать один вопрос.

```text
$wiki-query Telegram прислал одному боту два обновления с одинаковым update_id. Сколько событий сохранится и может ли клиент всё-таки получить два POST? Покажи подтверждение в wiki, первоисточнике и коде.
```

При включённой доставке и сохранённой записи повтор подтверждается без создания второго события. Если клиент обработал первый POST, но BotGate не получил успешный ответ, очередь может отправить тот же Event ID повторно. Без update_id входящие запросы обрабатываются независимо.

- [Повторы клиентского POST](wiki/concepts/webhook-delivery.md) · [архитектура, строки 83–89](raw/BG-ARCH.md#L83-L89) · [обработчик очереди](../app/Jobs/DeliverWebhookEventJob.php) · [тесты доставки](../tests/Feature/Jobs/DeliverWebhookEventJobTest.php).
